## Unit Testing Strategies

- Use pytest for Python testing framework
- Test business logic in isolation (Small parts of code at once, probably individual functions)
- Each new feature commit should include relevant unit tests(if it makes sense)
- tests for edge cases
- Focus on service boundaries and contracts
- Test failure scenarios and error handling

## Testing in CI/CD Pipelines

- Run unit tests on every commit
- Consider using feature flags (enable/disable feature) for production (configurable in env) so we can disable and enable features at runtime 
## Snapshot Testing

- Capture known-good input/output pairs
- Test entire flow from Kafka consumer to producer for given module
- Store snapshots in Github
- pytest-snapshot might be useful
- Update snapshots when intentionally changing behavior
